# ZoubirNasriShop — نسخة "zoubir vente" (مشروع مستقل)

هذا المجلد **منفصل تماماً** عن المتجر الأصلي: قاعدة بيانات جديدة، وجدول Google جديد، بدون أي ارتباط.

## 1) أنشئ مشروع Firebase جديد (لا تستعمل ZoubirShop القديم)
1. console.firebase.google.com → Add project → اسم جديد (مثلاً `zoubir-vente`).
2. Build → Firestore Database → Create database → Production mode → `eur3`.
3. Project settings ⚙︎ → Your apps → `</>` → انسخ `firebaseConfig`.
4. في `index.html` استبدل قيم `PASTE_...` (أعلى الملف). ما دامت `PASTE_` موجودة يشتغل المتجر محلياً فقط ولا يلمس أي قاعدة بيانات.
5. Firestore → Rules → الصق `firestore.rules` → Publish.

## 2) النسخ المتعددة
- كل نسخة = نفس `index.html` مع قيمة مختلفة لـ `window.STORE_ID` (`main`, `shop2`, `shop3` …) وموقع Netlify مختلف.
- أو نسخة واحدة برابط `?s=shop2`.
- المنتجات والطلبات والإعدادات في قاعدة واحدة (المشروع الجديد).
- ترتيب المنتجات والمنتج المميز محفوظان لكل نسخة في `shop/layout_<STORE_ID>`.
- من لوحة التحكم ← المنتجات: اختر النسخة، ثم ⤒ ▲ ▼ للترتيب، ودائرة "مميز" للبانر. "نسخ الترتيب من نسخة" يسرّع إنشاء نسخة جديدة.
- كل طلب يُحفظ مع `storeId` ويظهر اسم النسخة تحت رقم الطلب.

## 3) أشياء لازم تغيّرها
- رمز مرور اللوحة (الافتراضي `zoubir2026`) من الإعدادات.
- رابط Google Apps Script: أنشئ جدولاً جديداً وسكريبت جديداً (الحقل فارغ افتراضياً حتى لا تصل الطلبات للجدول الأصلي).
- Cloudinary: نفس الحساب مشترك مع الأصلي (الصور فقط)، لا مشكلة. غيّره فقط إذا أردت فصلاً كاملاً.

## 4) النشر
Netlify Drop: اسحب هذا المجلد كموقع **جديد**. لا ترفعه فوق موقع المتجر الأصلي.
